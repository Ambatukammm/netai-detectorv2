# Security policy

## Supported versions

Only the latest release of NetAI Detector receives security fixes.

## Reporting a vulnerability

Please report security problems **privately** through **Security → Report a vulnerability** on
this repository, not in a public issue. Include steps to reproduce, the version (shown at `/health`)
and your operating system.

## More detail

The full security model, data handling, network impact, hardening checklist and the algorithms,
APIs and third-party tools NetAI uses are described in
[SECURITY_AND_TECHNOLOGY.md](SECURITY_AND_TECHNOLOGY.md).
